Install In Under 5 Minutes

No build tools or command line required. Works in any Chromium browser.

1

Download & Unzip

Download sahayak-v1.0.0.zip and extract the folder onto your computer.

2

Open Chrome Extensions

Navigate to chrome://extensions and toggle Developer mode in the top-right to ON.

3

Load Unpacked

Click Load unpacked in the top-left and select the extracted Sahayak directory.
